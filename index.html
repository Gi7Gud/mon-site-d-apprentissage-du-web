Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Le Web (ou World Wide Web) est un système hypertexte public mondial qui fonctionne sur le réseau Internet et permet de consulter des pages de contenu à l'aide d'un navigateur.

Internet

Internet est le réseau informatique mondial, physique et décentralisé, qui relie des millions d'ordinateurs, de serveurs et d'appareils entre eux pour leur permettre de communiquer. C'est le support technologique obligatoire sur lequel reposent de multiples services, tels que le Web, le courrier électronique (e-mail) ou le transfert de fichiers.

Cloud

Le cloud (ou nuage) est un modèle technologique qui permet d'accéder à distance à des services informatiques (stockage, puissance de calcul, serveurs, logiciels) via le réseau Internet. Les fichiers et applications restent ainsi accessibles n'importe où et depuis n'importe quel appareil, tant que vous disposez d'une connexion Internet.

W3C

Le W3C (World Wide Web Consortium) est l'organisation internationale fondé en 1994 par Tim Berners-Lee, chargée de développer les standards techniques du Web afin d'en assurer la croissance à long terme.
Ce sont eux qui définissent et maintiennent les technologies fondamentales du Web, comme le HTML, le CSS ou les normes d'accessibilité (WCAG), garantissant ainsi que tous les sites Web fonctionnent de la même manière sur n'importe quel navigateur.

Partie 2 - Distinguez les langages du Web

Langages client

Les langages client (ou front-end) sont des langages de programmation et de balisage exécutés directement par le navigateur Internet de l'utilisateur.
Les trois principaux sont le HTML pour structurer le contenu, le CSS pour gérer la mise en page et les couleurs, et JavaScript pour rendre la page dynamique et interactive.

Navigateurs

Un navigateur est un logiciel client (comme Chrome, Firefox, Safari ou Edge) qui traduit le code HTML, CSS et JavaScript reçu d'Internet pour l'afficher sous forme de page web visuelle et interactive.
Il sert d'interface principale entre l'utilisateur et le World Wide Web, permettant de naviguer de site en site grâce aux liens hypertextes.

Langages serveur

Les langages serveur (ou back-end), comme PHP, Python, Java ou Ruby, sont exécutés sur le serveur distant, traitant les requêtes complexes, comme interroger les bases de données (ex: MySQL) et génèrent dynamiquement le code HTML qui sera lu par le navigateur.

Frameworks

Un framework (ou cadre de travail) est un ensemble d'outils, de bibliothèques de code et de règles architecturales préétablis qui structurent le développement d'une application. Il fournit une base solide et réutilisable, évitant au développeur de repartir de zéro et lui permettant de se concentrer sur les fonctionnalités spécifiques de son projet.

Bases de données

Une base de données est un système structuré qui permet de stocker, d'organiser, de modifier et de récupérer facilement de grandes quantités d'informations numériques.
Elle sert de mémoire centrale pour les applications et les sites web, garantissant la sécurité et l'accessibilité des données.

Site responsive

Un site « responsive » (ou adaptatif) est un site web dont la mise en page s'ajuste automatiquement à la taille de l'écran de l'appareil utilisé, qu'il s'agisse d'un smartphone, d'une tablette ou d'un ordinateur.
Il utilise des règles CSS spécifiques (les « media queries ») pour offrir une expérience de lecture et de navigation optimale sans avoir à créer plusieurs versions du même site.

Application mobile

Une application mobile est un logiciel développé spécifiquement pour être installé et exécuté sur un appareil mobile, comme un smartphone ou une tablette.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Un serveur est un ordinateur puissant et connecté en permanence à Internet, dont le rôle est de stocker des données et de fournir des services (comme l'envoi de pages web ou de fichiers) à d'autres appareils appelés clients.

Adresse IP

Une adresse IP (Internet Protocol) est un numéro d'identification unique attribué à chaque appareil connecté à un réseau informatique ou à Internet.
Elle fonctionne comme une adresse postale numérique, permettant aux ordinateurs de se localiser, de s'authentifier et d'échanger des données entre eux sans erreur de routage.

Nom d’hôte et DNS

Un nom d'hôte est un nom textuel lisible par l'humain attribué à un appareil sur un réseau pour l'identifier facilement sans avoir à retenir son adresse IP numérique.
C'est le système DNS (Domain Name System) qui se charge de traduire automatiquement ce nom d'hôte en son adresse IP correspondante.

Protocoles

Les protocoles sont un ensemble de règles et de normes standardisées qui définissent comment les appareils d'un réseau doivent structurer et échanger leurs données pour garantir que des systèmes différents (ordinateurs, serveurs, smartphones) se comprennent et communiquent sans erreur. On retrouve le HTTP/HTTPS pour l'affichage sécurisé des sites Web et le FTP pour le transfert de fichiers, qui reposent tous deux sur la suite fondamentale TCP/IP pour découper et acheminer les données sans perte sur le réseau.

Partie 4 - Identifiez les métiers du web

Développeurs

Un développeur informatique est un professionnel qui conçoit, écrit et maintient des logiciels, des sites web ou des applications mobiles en traduisant des besoins fonctionnels en lignes de code que la machine peut exécuter.

Product Managers et chefs de projets

Le Product Manager définit la vision, la stratégie et les fonctionnalités d'un produit en se concentrant sur la valeur apportée aux utilisateurs et à l'entreprise.
De son côté, le chef de projet orchestre l'exécution concrète de ce plan en s'assurant du respect des délais, du budget et de l'allocation des ressources.

Designers

Un designer est un professionnel qui conçoit et façonne l'aspect visuel, l'ergonomie et l'expérience d'un produit ou d'un service afin de le rendre à la fois esthétique, intuitif et parfaitement adapté aux besoins des utilisateurs.

Testeurs

Un testeur (ou ingénieur QA) est un professionnel chargé d'évaluer la qualité d'un logiciel ou d'une application en traquant les bugs et les dysfonctionnements afin de garantir sa conformité avec les exigences de départ avant sa livraison aux utilisateurs.

Techniciens informatique

Le technicien informatique est le garant du bon fonctionnement des outils numériques d'une entreprise : il installe le matériel, résout les pannes logicielles et matérielles, et accompagne au quotidien les utilisateurs pour assurer la continuité de leur activité.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Garde-robe du site web. Il structure et harmonise l'apparence visuelle du squelette HTML en gérant les couleurs, les polices de caractères, la mise en page, etc.

JavaScript

Front-End

Script d'exécution du site web. Il donne vie au squelette HTML et à la décoration CSS en rendant la page dynamique.

JavaScript

Back-End

Générateur dynamique du site web. Il s'exécute côté serveur (souvent via Node.js) pour gérer la logique de l'application, communiquer avec les bases de données, etc.

PHP

Back-End

Chef d'orchestre du serveur. Il s'exécute en arrière-plan pour traiter et interroger les bases de données et fabriquer instantanément les pages HTML personnalisées que l'internaute va recevoir sur son écran.

Java

Back-End

Processeur de données. Polyvalent et robuste, ce qui en fait un pilier pour les applications d'entreprise, les systèmes bancaires sécurisés, etc.

Python

Back-End

Langage de programmation épuré. Réputé pour sa syntaxe simple, il s'est imposé comme l'outil de référence pour analyser des volumes massifs de données (Data Science) et automatiser des tâches répétitives.

C#

Back-End

Le "C-Sharp" est un langage de programmation moderne développé par Microsoft. Il offre une sécurité maximale pour concevoir des applications web robuste et la grande majorité des jeux vidéo mondiaux via le moteur Unity.

SQL

Bases de données

Structured Query Language est le langage universel des bases de données. Il permet de communiquer directement avec un système de stockage pour enregistrer, modifier, trier et extraire précisément de grands volumes d'informations.

Boîte à outils du développeur

  • IDE comme VS Code : Un environnement de développement intégré est un logiciel complet qui rassemble en une seule interface un éditeur de texte intelligent, un assistant de coloration syntaxique, un outil de détection automatique des erreurs pour écrire et tester du code efficacement.
  • Github : Plateforme collaborative entre développeurs, elle permet d'héberger du code source en ligne, de suivre l'historique de chaque modification et de travailler à plusieurs sur un même projet sans risquer d'écraser le travail des autres.
  • Librairies / bibliothèques : Cela désigne un ensemble de code pré-écrit mis à disposition des développeurs pour résoudre des problèmes spécifiques sans avoir à redévelopper des fonctionnalités existantes.
  • Frameworks : Un cadre de travail est un ensemble d'outils qui guide le développeur pour coder plus rapidement, sécuriser son application et standardiser son architecture, plutôt que de coder à partir d'une page blanche.
    Exemples : React avec JavaScript, Django avec Python, Laravel avec PHP, etc.
